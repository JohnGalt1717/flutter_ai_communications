Shared pairing, sound floor, barge-in, and transcode for flutter_ai_communications.

This package is part of [flutter_ai_communications](https://github.com/JohnGalt1717/flutter_ai_communications). Apps depend on `flutter_ai_communications`; it pulls in this package. See the [repository README](https://github.com/JohnGalt1717/flutter_ai_communications#readme) for setup and usage.
