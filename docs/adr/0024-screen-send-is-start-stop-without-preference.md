# Screen send is start/stop Explicit selection; there is no Screen preference

Camera can come up with the Session because Camera preference resolves a default. Screen send is a picker action. There is no host-persisted “always share Monitor 2,” and start() must not auto-share on Join (privacy). CommunicationsManager.screenSources() enumerates. Session.startScreenShare / stopScreenShare start and stop the Production video path. A second startScreenShare replaces the source. The live source is Explicit selection and dies with the Session.
