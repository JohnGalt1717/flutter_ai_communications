# All-displays is a library stitch, not an OS capture item

Teams and Zoom list one display at a time; no production API but X11 exposes the virtual desktop as one target. All-displays is still a first-class Screen source because the host picker needs one id for “the whole viewport.” The Communications manager captures each display and stitches. Losing or adding a display rebuilds the stitch; losing every display ends screen send, not the Session.
