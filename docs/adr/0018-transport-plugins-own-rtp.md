# Transport plugins own RTP; the host owns signaling and layout

ADR-0015 kept PeerConnection out of the library and treated video as outbound sinks only. Zoom/Teams-class inbound display needs a wire without turning Session into a meeting client. Companion Transport plugins (WebRTC now, WebTransport later) own PeerConnection and RTP. They pull local audio and video from the Session, push inbound audio into Session playback so AEC sees far-end audio, and yield one Video surface per inbound stream. The host owns signaling, roster, chat, and tile layout. Session has no PeerConnection types. Host-pumped PCM Transport remains valid for audio-only paths that are not a plugin.
