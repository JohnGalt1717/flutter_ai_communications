# Lobby is a Session; in-call camera settings are Camera preview

Lobby needs the same Session machine as a meeting — catalogs, Capture stream, playback, camera, Test record — with different attachments (no Transport plugin). The host stops that Session and starts a new one, optionally passing Session settings copied from the old Session; the objects are not shared, so testing cannot leak onto the wire. There is no joinFromLobby helper. In-call audio device changes and in-call selectCamera without a settings UI are live switches. In-call camera settings Camera-off the Session (audio continues) and open a video-only Camera preview; the host stops preview and selects/resumes camera. Camera preview is not a Session. There is no in-call audio preview and no in-call Test record.
